# 🐢 Python Turtle Simulator

A simple **Python Turtle simulator** made with Python's built-in `turtle` module.

This project lets you experiment with Turtle graphics, movement, drawing, and simple game-like features.

## ✨ Features

* 🐢 Control a Turtle
* ⌨️ Keyboard movement
* 🎨 interact with objects
* 🏠 Build and explore a Turtle environment
* 🕹️ Beat (hard or easy) levels and unlock (sometimes crazy) endings  
* 📚 Made with beginner-friendly Python

## 🛠️ Built With

* **Python**
* **Turtle Graphics**
* Python's built-in libraries

No external game engine is required.

## 🚀 How to Run

### 1. Install Python

Make sure Python is installed on your computer.

### 2. Download the project

Clone this repository or download the files.

```bash
git clone https://github.com/SaiyaoYinIsNiuBi/py-turtle-simulator.git
```

### 3. Run the program

Open the main Python file and run it:

```bash
python main.py
```

You can also run it using **IDLE** by opening the Python file and selecting **Run → Run Module**.

## 🎮 Controls

| Key | Action     |
| --- | ---------- |
| `W` | Move up    |
| `A` | Move left  |
| `S` | Move down  |
| `D` | Move right |

More controls may be added as the project develops.
